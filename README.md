# AI Inventory Management System

## Overview

AI Inventory Management System is a web-based inventory management application built using FastAPI, MySQL, HTML, CSS, and JavaScript. It helps users manage products, track sales, monitor stock levels, visualize inventory analytics, and automatically update inventory after each sale.

## Features

- User Login Authentication
- Dashboard
- Add Product
- View Products
- Search Products
- Sort Products
- Filter Products
- Update Product
- Delete Product
- Record Sales
- Automatic Stock Reduction
- Sales History
- Low Stock Alert
- Out of Stock Detection
- AI Stock Prediction
- Charts & Analytics
- CSV Export
- Pagination
- MySQL Database Integration

## Technologies Used

- FastAPI
- Python
- MySQL
- SQLAlchemy
- HTML
- CSS
- JavaScript
- Chart.js

## How to Run

### 1. Install Requirements

```bash
pip install -r requirements.txt
```

### 2. Start the Backend

```bash
uvicorn main:app --reload
```

### 3. Open FastAPI Docs

```
http://127.0.0.1:8000/docs
```

### 4. Open Frontend

```
index.html
```
