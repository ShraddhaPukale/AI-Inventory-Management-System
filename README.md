# AI Inventory Management System

## Overview

AI Inventory Management System is a web-based inventory management application built using FastAPI, MySQL, HTML, CSS, and JavaScript. It helps users manage products, track sales, and automatically update inventory after each sale.

## Features

- Add Product
- View Products
- Search Products
- Update Product
- Delete Product
- Record Sales
- Automatic Stock Reduction
- Sales History
- Dashboard
- MySQL Database Integration

## Technologies Used

- FastAPI
- Python
- MySQL
- SQLAlchemy
- HTML
- CSS
- JavaScript

## How to Run

1. Install requirements

```bash
pip install -r requirements.txt
```

2. Start the FastAPI server

```bash
uvicorn main:app --reload
```

3. Open:

```
http://127.0.0.1:8000/docs
```

4. Open the frontend:

```
index.html
```
